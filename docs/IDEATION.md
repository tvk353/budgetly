Stage 1 — Ideation & Brainstorming
Status: Approved
Project: Personal Expense Tracker
Product vision
Build a personal expense tracker inspired by Wallet-style finance apps. It should work well on an iPhone, be installable from the browser onto the iPhone Home Screen as a Progressive Web App (PWA), and also support desktop browsers.
Main goals

- Track expenses and refunds manually.
- Support one Shared Household workspace and a private Personal workspace for each user.
- Keep the first version online-only, with cloud synchronization.
- Use Indian Rupees (₹).
- Make the interface mobile-first, clean, and iOS-inspired.
- Aim for ₹0 recurring cost by using free tiers where practical, while documenting their limits.
  Initial users and access
- Two users sign in using email OTP.
- Both users can use the Shared Household workspace.
- Each user also has a separate private Personal workspace.
- Shared financial data is stored once in the household workspace.
- Personal data is never shared automatically.
  Not included in the first version
- Bank integrations.
- Automatic transaction detection.
- Receipt scanning or OCR.
- Offline transaction entry and synchronization.
- Bank/card/cash account balance tracking.
- Transaction attachments.
- Spending notifications.
  Intended workflow

1. Open the app on an iPhone or desktop.
2. Sign in.
3. Choose Shared Household or Personal workspace.
4. View the dashboard and monthly budget.
5. Add expenses or refunds manually.
6. Review savings, trackers, reports, and historical records.
   Why this stage exists
   Stage 1 defines what the product is and the problem it should solve. It establishes direction before detailed requirements, architecture, database design, or code.
